N-body gravity: f32 vs f64

The same seeded scene twice, one in 32-bit floats and one in 64-bit. At the start they differ only by f32's rounding of the initial state, far too small to see. Gravity between many bodies is chaotic, so that difference grows exponentially until the two runs look unrelated. Set softening to 0 to watch close passes fling bodies apart.

Divergence

Root-mean-square distance between matching bodies in the two panels, in meters (log scale). Roughly a straight line while it grows: exponential growth, the signature of chaos.

Energy error

|ΔE / E₀| per panel. Changing softening changes the potential itself, so it restarts this plot from the new energy.

Cost

Measured time per physics step at each N tried (smoothed). Direct summation does N(N−1)/2 pair interactions, so a flat ns/pair column means cost grows as N²: double N, four times the cost.
