# Public API snapshots

One file per library crate: its public API as `cargo public-api -sss`
lists it (auto-trait, blanket and derived impls left out), generated by
`cargo xtask api` on a pinned nightly (`xtask/src/api.rs`).

The pre-push hook runs `cargo xtask api --check`, which fails while a
snapshot is stale: a change to a crate's surface has to be recorded
here, so it shows up in the PR's diff and gets reviewed as a decision
(`docs/api-audit.md`). Regenerate with `cargo xtask api`; don't edit by
hand. The `cdylib`s aren't here: their surface is the C ABI, checked
against `site/js/*.d.ts` by `cargo xtask site`.
